# AT コマンド表

Author: yuichi(更新 2026-10-21)

このツール(`Monitor` / `Probe`)に関係する AT コマンドの一覧です。

- 「意味」「応答の形」は、標準仕様(ITU-T V.250、3GPP TS 27.007)に基づく**一般的な内容**です。
- 右端の「IsatPhone 2 での確認」欄は、**2026-10-14 に実機で `Probe.bat` を実行した結果**です。ほかの機器で使うときは、その機器で `Probe.bat` を実行して確かめてください。
- 対応範囲の調べ方・項目の足し方は [at-commands.md](at-commands.md) を参照してください。

凡例

| 記号 | 意味 |
|---|---|
| 種別 **読出** | 状態を読むだけ。機器の設定を変えない |
| 種別 **設定** | 機器の設定や状態を変える。Probe には入れない |
| 種別 **動作** | 発信・切断など、実際に動作させる(通話料が発生しうる) |
| 本ツール **Monitor** | `Monitor.ps1` が周期的に送る |
| 本ツール **Probe** | `probe_commands.txt` に入っている |
| 本ツール **Extras** | `Config.ps1` の `$Extras` に書けば画面に出せる |
| 本ツール **発信** | 定時試験発信(`$CallTimes`)で使う |
| 確認 **対応** | 応答が返った(`OK` まで) |
| 確認 **未対応** | `ERROR` または `+CME ERROR` が返った |
| 確認 **使用禁止** | 送ると機器に悪影響がある |
| 確認 **再確認** | 結果が信頼できない(直前のコマンドの影響など)。もう一度調べる |

## 0. IsatPhone 2 の Probe 結果(2026-10-14)

| 結果 | コマンド |
|---|---|
| 対応 | `AT` `ATI` `AT+CGMI` `AT+CGMM` `AT+CGMR` `AT+CSQ` `AT+CSQ=?` `AT+CREG?` `AT+CREG=?` `AT+COPS?` `AT+CPAS` `AT+CPIN?` |
| 未対応 | `AT+CLAC`(`+CME ERROR: 25`)、`AT+CGREG?`・`AT+CGATT?`(`+CME ERROR: 4`)、`AT+GPSINFO`(`+CME ERROR: 600`) |
| **使用禁止** | `AT+CBC`(応答がなく、その後のコマンドも応答しなくなる。Probe では後続 5 コマンド・約 30 秒にわたって無応答のあと、`AT+GPSINFO` でようやく応答が戻った) |
| 再確認 | `AT+CLCC`、`AT+CGPS?`、`AT+CGPSINFO`、`AT+CGNSINF`、`AT+QGPS?`(`AT+CBC` の直後で応答がなかった。`AT+CBC` を外して調べ直す) |

`+CME ERROR` の番号のうち、`4` は「その操作に対応していない」、`25` は「文字列が不正」です(3GPP TS 27.007)。`600` は標準の範囲外で、メーカー独自の番号です。

## 1. 結果コード(応答の終わり)

`AtIo.exe` は、次のいずれかの行を受信した時点で「応答が終わった」と判断します。

| 結果コード | 意味 |
|---|---|
| `OK` | コマンドを実行した |
| `ERROR` | コマンドが未対応、または構文が不正 |
| `+CME ERROR: <n>` | 機器・ネットワーク側のエラー(`<n>` は原因番号。`AT+CMEE=2` で文字表示にできる) |
| `NO CARRIER` | 接続できなかった、または切断された |
| `BUSY` / `NO ANSWER` / `NO DIALTONE` | 発信時に、話中 / 応答なし / 発信音なし |

どれも受信できないまま待ち時間(`WaitSec`)が過ぎると、そこで終わります。Probe ではこれを `NO RESPONSE` と表示します。

## 2. 基本(V.250)

| コマンド | 意味 | 応答の形 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|---|
| `AT` | 通信できるかの確認 | `OK` | 読出 | Probe | 対応 |
| `ATE0` / `ATE1` | エコー OFF / ON | `OK` | 設定 | `AtIo.exe` が毎回送信(`ATE0V1`) | 対応(`AtIo.exe` 経由で正常) |
| `ATV0` / `ATV1` | 応答を数字 / 文字で返す | `OK` | 設定 | `AtIo.exe` が毎回送信(`ATE0V1`) | 対応(`AtIo.exe` 経由で正常) |
| `ATI` | 機器の識別情報 | 機種により異なる文字列 | 読出 | Probe | 対応 |
| `ATD<番号>;` | 音声発信(末尾の `;` が音声通話の意味) | `OK`(呼出開始)/ `NO CARRIER` / `BUSY` など | 動作 | 発信 | 未確認 |
| `ATH` | 切断 | `OK` | 動作 | 発信(発信後の切断) | 未確認 |
| `ATA` | 着信に応答 | `OK` | 動作 | — | 未確認 |
| `ATZ` | 保存済みの設定に戻す | `OK` | 設定 | — | — |
| `AT&F` | 工場出荷設定に戻す | `OK` | 設定 | — | — |

## 3. 機器情報(3GPP TS 27.007)

| コマンド | 意味 | 応答の形 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|---|
| `AT+CGMI` | メーカー名 | 文字列 | 読出 | Probe | 対応 |
| `AT+CGMM` | 機種名 | 文字列 | 読出 | Probe | 対応 |
| `AT+CGMR` | ファームウェアの版 | 文字列 | 読出 | Probe | 対応 |
| `AT+CGSN` | シリアル番号(IMEI など) | 数字列。**個体を特定できる情報** | 読出 | Probe(既定ではコメントアウト) | 未実施 |
| `AT+CLAC` | 対応しているコマンドの一覧 | `+CLAC: ...` または行ごとに 1 コマンド | 読出 | Probe | **未対応**(`+CME ERROR: 25`) |

## 4. 信号・ネットワーク(3GPP TS 27.007)

| コマンド | 意味 | 応答の形 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|---|
| `AT+CSQ` | 信号品質 | `+CSQ: <rssi>,<ber>` | 読出 | **Monitor**・Probe | 対応(例 `+CSQ: 37,0`) |
| `AT+CSQ=?` | 返しうる値の範囲 | 例: `+CSQ: (0-31,99),(0-7,99)` | 読出 | Probe | 対応 `+CSQ: (0-55,99),(0-15,99)` |
| `AT+CREG?` | 回線交換(音声)網の登録状態 | `+CREG: <n>,<stat>` | 読出 | **Monitor**・Probe | 対応(例 `+CREG: 1,1`) |
| `AT+CREG=?` | `AT+CREG` に設定できる値 | 例: `+CREG: (0-2)` | 読出 | Probe | 対応 `+CREG: (0-2)` |
| `AT+CGREG?` | パケット網の登録状態 | `+CGREG: <n>,<stat>` | 読出 | Probe | **未対応**(`+CME ERROR: 4`) |
| `AT+COPS?` | 現在の事業者 | `+COPS: <mode>[,<format>,<oper>]` | 読出 | Probe・Extras 例 | 対応 `+COPS: 0,2,"90111"` |
| `AT+CGATT?` | パケット網への接続状態 | `+CGATT: <0 or 1>` | 読出 | Probe | **未対応**(`+CME ERROR: 4`) |

### `<rssi>`(`AT+CSQ` の 1 つ目の値)

| `<rssi>` | 受信電力 |
|---|---|
| 0 | -113 dBm 以下 |
| 1 | -111 dBm |
| 2 〜 30 | -109 〜 -53 dBm(2 dB 刻み) |
| 31 | -51 dBm 以上 |
| 99 | 不明、または測定できない |

この表と換算式 `dBm = -113 + 2 × <rssi>`(0〜31)は、GSM の定義です。

**IsatPhone 2 では使えません。** `AT+CSQ=?` の応答が `(0-55,99),(0-15,99)` で、rssi は 0〜55、ber は 0〜15 の独自の目盛りです(2026-10-14 確認)。実測は屋内・外部アンテナで 37〜38 でした。GSM の式に当てはめると -39 dBm のようなありえない値になるため、このツールは dBm に換算せず、生の値を `値 / 最大値`(例 `37 / 55`)で表示します。最大値は `Config.ps1` の `$RssiMax` です。値と実際の受信品質(C/N0 など)との対応はまだわかっていません。

端末が `99` を返したときはグラフ上で `0` として描き、画面に `圏外 (99)` と出します。端末から値を取れなかったとき(取得失敗)は、グラフの線を途切れさせ、`圏外` とは区別します。

### `<ber>`(`AT+CSQ` の 2 つ目の値)

`0`〜`7` がビット誤り率の段階、`99` が不明です(GSM の定義。IsatPhone 2 は `0`〜`15`)。機器によっては常に `99` を返します(このツールの `Ber` 表示は、返ってきた値をそのまま出します)。

### `<n>`(`AT+CREG?` の 1 つ目の値)

| `<n>` | 意味 |
|---|---|
| 0 | 登録状態が変わっても通知しない |
| 1 | 登録状態が変わると `+CREG: <stat>` を自分から送ってくる(非同期通知) |
| 2 | 1 に加えて、位置情報も送ってくる |

IsatPhone 2 は `1` でした。別のコマンドの応答に `+CREG:` が紛れ込むことがあるので、試験ログでは `+CREG:` が 2 行以上あったときに WARN を出します。

### `<stat>`(`AT+CREG?` の登録状態)

| `<stat>` | 意味 | このツールの既定の表示 |
|---|---|---|
| 0 | 未登録、探索もしていない | 未登録 (Not registered) |
| 1 | 登録済み(ホーム網) | 同期完了 (Registered) |
| 2 | 未登録、探索中 | 衛星探索中 (Searching) |
| 3 | 登録拒否 | 拒絶 (Denied) |
| 4 | 不明 | 不明 (Unknown) |
| 5 | 登録済み(ローミング) | ローミング登録 (Roaming) |

表示名は `Config.ps1` の `$RegText` で変えられます。

### `AT+COPS?` の事業者番号

IsatPhone 2 は `+COPS: 0,2,"90111"` を返しました。`2` は数字表記の意味で、`901` は国際(衛星などの国番号を持たない網)の MCC、`11` は Inmarsat の MNC です。登録先の確認に使えます。

## 5. 機器の状態・通話(3GPP TS 27.007)

| コマンド | 意味 | 応答の形 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|---|
| `AT+CPAS` | 機器の動作状態 | `+CPAS: <pas>`(0=待機、3=着信中、4=通話中、5=スリープ など) | 読出 | Probe | 対応(例 `+CPAS: 0`) |
| `AT+CPIN?` | SIM の PIN 状態 | `+CPIN: READY` / `SIM PIN` など | 読出 | Probe | 対応 |
| `AT+CBC` | バッテリー状態 | `+CBC: <状態>,<残量%>[,<電圧>]` | 読出 | **入れない** | **使用禁止**(無応答になり、後続も返らない) |
| `AT+CLCC` | 現在の通話の一覧 | `+CLCC: ...`(通話がなければ `OK` のみ) | 読出 | Probe | 再確認(`AT+CBC` の直後で応答なし) |
| `AT+CMEE=<n>` | エラー表示の形式(0=`ERROR` のみ、1=数字、2=文字) | `OK` | 設定 | — | 未確認 |
| `AT+CFUN=<n>` | 機器の機能レベル(無線の ON/OFF など) | `OK` | 設定 | — | — |

`AT+CLCC` は、試験発信で「相手が鳴動したか」を判定するのに使える見込みのコマンドです(`<stat>` が `3` = 相手呼出中)。`AT+CBC` を外して、改めて確かめてください。

## 6. GPS 探索(メーカー独自)

標準には、GPS の衛星数や信号強度を返すコマンドがありません。次は**他社モジュールで使われている例**を、探索用に Probe に入れたものです。

| コマンド | 他社での意味 | 種別 | 本ツール | IsatPhone 2 での確認 |
|---|---|---|---|---|
| `AT+CGPS?` | GPS の ON/OFF 状態 | 読出 | Probe | 再確認(`AT+CBC` の影響) |
| `AT+CGPSINFO` | 測位情報(緯度経度など) | 読出 | Probe | 再確認(`AT+CBC` の影響) |
| `AT+CGNSINF` | GNSS の状態・測位情報 | 読出 | Probe | 再確認(`AT+CBC` の影響) |
| `AT+QGPS?` | GPS の ON/OFF 状態 | 読出 | Probe | 再確認(`AT+CBC` の影響) |
| `AT+GPSINFO` | 測位情報 | 読出 | Probe | 未対応(`+CME ERROR: 600`) |
| `AT+CGPS=1` など | GPS を起動 | **設定** | — (入れない) | — |

`AT+GPSINFO` だけはエラーが返りました。`600` はメーカー独自の番号で、「コマンドとしては受け付けたが、何らかの理由で実行できない」可能性もあります。番号の意味はわかっていません。

衛星数と信号強度(SNR)は、NMEA 出力の `$GPGSV` 文に含まれます。NMEA が別の COM ポートに出る機器もあります(詳細は [at-commands.md](at-commands.md))。

## 7. 使い方の例

`AtIo.exe` は、コマンドを引数で渡して 1 回だけ送ります。

```
AtIo.exe COM3 115200 "AT+CSQ" 3
AtIo.exe COM3 115200 "ATD+819012345678;" 20 "ATH"
```

書式は `AtIo.exe <ポート> <ボーレート> <コマンド> [待ち秒] [後続コマンド]` です。

引数の説明は、`AtIo.exe -HELP` でも表示できます。

画面に項目を足すには、`Config.ps1` の `$Extras` に書きます(`Probe` で `OK` が返ったコマンドだけ)。

```powershell
$Extras = @(
    @{ Name = 'Operator'; Cmd = 'AT+COPS?'; Regex = '\+COPS:\s*\d+,\d+,"([^"]*)"' }
)
```

IsatPhone 2 では、この例で `90111` が表示されます。**`AT+CBC`(バッテリー)は IsatPhone 2 では使わないでください。**

## 8. コマンドの 3 つの書式

| 書式 | 例 | 意味 |
|---|---|---|
| 実行 / 設定 | `AT+CMEE=2` | 値を設定する、または実行する |
| 読出 | `AT+CREG?` | 現在の設定値を読む |
| 試験 | `AT+CREG=?` | 設定できる値の範囲を読む |

`AT+CSQ` のように `?` や `=` が付かないものは、「実行」(測定して結果を返す)です。
